# ⚙️ Server Resource Monitor (Monitoramento de Infraestrutura)

Ferramenta de diagnóstico em tempo real que monitora os recursos da máquina física ou servidor local. O script rastreia o consumo de CPU, Memória RAM e Espaço em Disco, gerando um arquivo de log local com alertas sempre que um componente ultrapassa o limite crítico estabelecido (ex: 85%).

**Problema resolvido:** Previne quedas de servidores e gargalos operacionais alertando preventivamente sobre picos de uso.

### 🛠️ Tecnologias Utilizadas
* Python
* Bibliotecas: `psutil`, `datetime`

### 🚀 Destaque Técnico
Interação direta com hardware, monitoramento de infraestrutura (Linux/Windows Server) e geração de logs operacionais.
